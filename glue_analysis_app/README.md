# Glue Analysis App

This is a refactored version of the Glue Analysis App.

## Structure

- `app.py`: Main entry point.
- `pages/`: Streamlit multipage scripts.
- `utils/`: Image processing, session state, plotting, and IO helpers.
- `config/`: Configuration and default settings.
- `data/`: Stores CSVs and intermediate results.

## Run

```bash
streamlit run app.py
```
